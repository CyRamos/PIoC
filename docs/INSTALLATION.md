# 🚀 PIoC Installation Guide

This guide will help you install and run the PIoC (Pretty IoC) Cyber Threat Intelligence platform.

## 📋 Prerequisites

- Python 3.11+ (recommended)
- pip (Python package installer)
- Git (for cloning the repository)

## 🔧 Installation Methods

### Method 1: Quick Install (Recommended for Users)

```bash
# Clone the repository
git clone https://github.com/CyRamos/PIoC
cd PIoC

# Install dependencies
pip install -r requirements.txt

# Run the application
python launcher.py
```

### Method 2: Development Install (For Contributors)

```bash
# Clone the repository
git clone https://github.com/CyRamos/PIoC
cd PIoC

# Create virtual environment (recommended)
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On Linux/Mac:
source venv/bin/activate

# Install development dependencies
pip install -r requirements-dev.txt

# Run the application
python launcher.py
```

### Method 3: Using pip-tools (For Advanced Users)

```bash
# Clone the repository
git clone https://github.com/CyRamos/PIoC
cd PIoC

# Install pip-tools
pip install pip-tools

# Generate fresh requirements (optional)
pip-compile requirements.in
pip-compile requirements-dev.in

# Install dependencies
pip install -r requirements.txt

# Run the application
python launcher.py
```

## 🎯 Quick Start

Once installed, you can:

1. **Launch GUI + API**:
   ```bash
   python launcher.py
   # Select option 3: Both GUI and API
   ```

2. **Launch API Only**:
   ```bash
   python launcher.py
   # Select option 2: API only
   # API will be available at http://localhost:8000
   ```

3. **Launch GUI Only**:
   ```bash
   python launcher.py
   # Select option 1: GUI only
   # GUI will be available at http://localhost:8501
   ```

## 🐛 Troubleshooting

### Common Issues

1. **FastAPI Version Error**:
   ```
   Could not find a version that satisfies the requirement fastapi==0.104.1
   ```
   **Solution**: Use the locked requirements.txt generated by pip-tools

2. **Python Version**:
   Ensure you're using Python 3.11+:
   ```bash
   python --version
   ```

3. **Missing Dependencies**:
   If you get import errors, reinstall:
   ```bash
   pip install -r requirements.txt --force-reinstall
   ```

4. **Port Conflicts**:
   If ports 8000/8501 are busy, use:
   ```bash
   python launcher.py
   # Choose custom ports when prompted
   ```
